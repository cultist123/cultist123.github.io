# Bellman 方程：价值迭代与策略迭代


Bellman 方程把“一个状态的价值”拆成“这一步奖励 + 折扣后的下一状态价值”；价值迭代反复套用最优方程，让奖励一格格往回传直到收敛，策略迭代则交替做评估和改进。两者都要求知道环境模型，这正是 model-free 方法要解决的问题。

## 1. V 和 Q

- $V^\pi(s)$：**状态价值**，从状态 $s$ 出发，之后按策略 $\pi$ 走，能拿到的期望回报
- $Q^\pi(s, a)$：**动作价值**，在状态 $s$ **先做动作 $a$**，之后再按 $\pi$ 走，能拿到的期望回报
- 关系：$V^\pi(s) = \sum_a \pi(a|s)\, Q^\pi(s, a)$；最优时 $V^*(s) = \max_a Q^*(s, a)$

> **追问：有了 V 为什么还要 Q？**
> 只有 $V$ 时，想知道哪个动作最好，必须知道每个动作会把你带到哪个 $s'$，也就是需要环境模型；有了 $Q$，直接选 $\arg\max_a Q(s, a)$ 就行，不需要模型。所以不知道环境的方法（如 Q-learning）学的是 $Q$。

## 2. Bellman 方程

核心思想：**价值 = 这一步的奖励 + $\gamma$ × 下一个状态的价值**。环境有随机性，所以要对所有可能取平均。

#### 2.1 Bellman 期望方程（评价一个给定的策略 $\pi$）

$$
V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} p(s'|s,a)\,[\,r + \gamma V^\pi(s')\,]
$$

- 读法：先对“我可能选的动作”取平均，再对“环境可能把我送到哪”取平均
- $r$ 是 $r(s, a, s')$，取决于这一步的状态、动作和结果

#### 2.2 Bellman 最优方程（直接找最好的）

$$
V^*(s) = \max_a \sum_{s'} p(s'|s,a)\,[\,r + \gamma V^*(s')\,]
$$


$$
Q^*(s,a) = \sum_{s'} p(s'|s,a)\,[\,r + \gamma \max_{a'} Q^*(s',a')\,]
$$

- 和期望方程的区别只有一个：**把“对动作取平均”换成了“取最大”**
- 意思是：最优的价值 = 选最好的那个动作能拿到的价值

## 3. 价值迭代（Value Iteration）

不知道 $V^*$，就**反复套用 Bellman 最优方程**：

1. 把所有 $V$ 设成 0
2. 每一轮，用旧的 $V$ 按最优方程算出新的 $V$
3. 重复到 $V$ 不再变化，再对每个状态选让价值最大的动作，得到最优策略

#### 例子：走廊

```
[0] → [1] → [2] → [3] → [4 终点]
```

- 动作：向左 / 向右（确定的）；在 0 向左撞墙留在原地
- 奖励：到达终点 +10，其他每步 −1；$\gamma = 0.9$；终点 $V(4) = 0$

| 轮次 | V(0)     | V(1)    | V(2)  | V(3)   |
| ---- | -------- | ------- | ----- | ------ |
| 0    | 0        | 0       | 0     | 0      |
| 1    | −1       | −1      | −1    | **10** |
| 2    | −1.9     | −1.9    | **8** | 10     |
| 3    | −2.71    | **6.2** | 8     | 10     |
| 4    | **4.58** | 6.2     | 8     | 10     |

- 例：第 4 轮 $V(0) = -1 + 0.9 \times V(1) = -1 + 0.9 \times 6.2 = 4.58$
- 规律：**终点的好消息每一轮往回传一格**，最终得到最优策略：一直往右

> **追问：为什么价值迭代一定会收敛？**
> 每做一轮，新 $V$ 和真实 $V^*$ 的最大误差至少缩小为原来的 $\gamma$ 倍。$\gamma < 1$，所以误差按 $\gamma^k$ 趋于 0。

## 4. 策略迭代（Policy Iteration）

两步交替：

1. **策略评估**：固定当前策略 $\pi$，用 Bellman **期望**方程反复迭代，算出 $V^\pi$
2. **策略改进**：每个状态都换成让 $Q^\pi(s, a)$ 最大的动作（贪心），得到新策略
3. 重复，直到策略不再变化

> **追问：价值迭代和策略迭代有什么区别？**
> 价值迭代每轮只做一次“取最大”的更新，不单独维护策略，最后才提取策略；策略迭代每轮要先把当前策略完整评估一遍，再改进策略。策略迭代需要的轮数少，但每轮计算量大；价值迭代每轮便宜，但轮数多。两者都能收敛到最优策略。

## 5. 动态规划的局限

- 前提：**必须知道环境模型** $p(s'|s,a)$ 和奖励，知道每个动作会把你带到哪、给多少奖励
- 真实场景做不到：不知道这一步会发生什么，只能真的去试
- 而且要遍历所有状态，状态空间很大时（比如围棋、文本）根本存不下
- 下一步要解决：**不知道模型，只靠试出来的经验怎么学价值函数**（model-free 方法）

> **追问：动态规划、蒙特卡洛（MC）、时序差分（TD）有什么区别？**
>
> |          | 需要环境模型 | 怎么估计价值                                             |
> | -------- | ------------ | -------------------------------------------------------- |
> | 动态规划 | 需要         | 用模型对所有可能的 $s'$ 求期望                           |
> | 蒙特卡洛 | 不需要       | 跑完整一局，用真实回报 $R_t$ 更新，无偏但方差大          |
> | TD       | 不需要       | 只走一步，用 $r + \gamma V(s')$ 当目标更新，方差小但有偏 |

> **追问：这和 LLM 的 RL 有什么关系？**
> PPO 里的 value model（critic）学的就是 $V(s)$，用来判断某个回答比平均水平好多少（优势 $A = Q - V$）；GRPO 的改进之一就是去掉这个 value model，改用同一个问题下多个回答的平均奖励当基准。
