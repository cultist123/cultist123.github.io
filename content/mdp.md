# 强化学习基础：MDP、策略与回报


MDP 用 $[S, A, T, r, \gamma]$ 描述“智能体和环境的交互”；策略 $\pi$ 决定每个状态做什么，回报 $R_t$ 是未来奖励的折扣总和，强化学习的目标就是找到让期望回报最大的策略 $\pi^*$。

## 1. MDP 五元组

$$
[S, A, T, r, \gamma]
$$

- $S$：所有可能的**状态**集合

- $A$：所有可能的**动作**集合

- $T(s, a, s')$：**状态转移函数**，

- $$
  T(s, a, s') = P(S_{t+1} = s' \mid S_t = s, A_t = a)
  $$

  - 在状态 $s$ 下执行动作 $a$，下一步变成状态 $s'$ 的概率

- $r$：**即时奖励函数**，在某个状态 / 动作下当场得到多少奖励

- $\gamma$：**折扣因子**（0～1），越接近 1 越看重长期回报，越小越看重眼前收益

#### 例子：走廊机器人

```
[ 起点 ] → [ 中间 ] → [ 终点 +10 ]
```

| 概念          | 例子                                       |
| ------------- | ------------------------------------------ |
| 状态 $S$      | {起点, 中间, 终点}                         |
| 动作 $A$      | {向左, 向右}                               |
| 转移 $T$      | 在起点选向右：90% 到中间，10% 打滑原地不动 |
| 奖励 $r$      | 到终点 +10，其他每步 0                     |
| 折扣 $\gamma$ | 0.9                                        |
| 策略 $\pi$    | 在任何位置都 100% 向右                     |

**交互循环**：看状态 → 按策略选动作 → 环境按 $T$ 转移到新状态并给出奖励 $r$ → 再看新状态……

## 2. 策略 $\pi$

- $\pi(s, a)$（也写作 $\pi(a \mid s)$）：在状态 $s$ 时，以多大概率选择动作 $a$
- 简单理解：**“看到什么状态就做什么事”的规则**

## 3. 回报（Return）

$$
R_t = \sum_{k=t}^{T} \gamma^{k-t}\, r_k(s_k, a_k)
$$

- 从时刻 $t$ 到结束时刻 $T$ 的**总折扣回报**：后面每一步的奖励乘上折扣 $\gamma^{k-t}$ 后加起来
- 注意区分：**奖励 $r$** 是每一步当场拿到的分数；**回报 $R_t$** 是从现在到结束所有奖励的折扣总和
- 注意：这里的 $T$ 是结束时刻，和转移函数 $T(s, a, s')$ 是同一个字母两个意思

**例子**：每步奖励依次为 0, 0, 10

- $\gamma = 0.9$：$R_0 = 0 + 0.9 \times 0 + 0.9^2 \times 10 = 8.1$
- $\gamma = 0.5$：$R_0 = 0.5^2 \times 10 = 2.5$，越远的奖励打折越多

> **追问：为什么要打折？**
> ① 越远的未来越不确定；② 任务没有终点（无限长）时，不打折的话总和会变成无穷大，没法比较不同策略。

## 4. 最优策略

$$
\pi^* = \arg\max_\pi \ \mathbb{E}_\pi[R_t] \quad \text{for all } t
$$

- 在所有可能的策略里，让**期望回报**最大的那一个
- 要取期望，是因为转移有随机性（会打滑），同一个策略每次跑出来的 $R_t$ 都不一样

## 5. 和 LLM 强化学习的对应

| MDP        | 大模型生成                                        |
| ---------- | ------------------------------------------------- |
| 状态 $s$   | prompt + 已经生成的 token                         |
| 动作 $a$   | 下一个 token                                      |
| 策略 $\pi$ | **大模型本身**：给定前文，输出下一个 token 的概率 |
| 转移 $T$   | 确定的：把选中的 token 接到后面                   |
| 奖励 $r$   | 通常只在最后给：奖励模型打分，或答案对不对        |

用 RL 训练大模型 = 调整模型参数（策略 $\pi$），让生成的回答拿到的期望奖励最大。PPO、GRPO 解决的是“具体怎么调”。
