# Padding Mask：填充掩码与因果掩码

### Padding Mask（填充掩码）
**作用**：GPU 要求输入是规整的矩阵，句子长短不一时用 `[PAD]` 补齐。Padding Mask 用来告诉模型哪些是真词、哪些是补位的 PAD，计算时忽略 PAD。
**例子**：batch_size = 2，seq_len = 4
- 句子 A：[我, 爱, 你, PAD]
- 句子 B：[机, 器, 学, 习]
**掩码**（1 保留，0 忽略）：
- 句子 A：[1, 1, 1, 0]
- 句子 B：[1, 1, 1, 1]
**作用到注意力分数上**：
把 0 的位置换成 -inf，1 的位置换成 0，再加到分数矩阵 [batch, n_head, seq_len, seq_len] 上（广播）。以句子 A 为例，加上的掩码为：
        我    爱    你    PAD
  我   [ 0,   0,   0,  -inf ]
  爱   [ 0,   0,   0,  -inf ]
  你   [ 0,   0,   0,  -inf ]
  PAD  [ 0,   0,   0,  -inf ]
**原理**：PAD 所在列的分数变为 -inf，softmax 后权重为 0，加权求和时完全忽略 PAD，不会污染真实词的语义。
**与因果掩码的关系**：两者都是加到分数上的 -inf 掩码，可以相加后一起使用；因果掩码挡住"后面的词"，Padding Mask 挡住"PAD 列"。

在实际的 GPT 或 LLaMA 解码器中，掩码是上述两种类型**相加**的：
1. 先生成一个下三角矩阵（因果掩码）。
2. 再根据 `[PAD]` 的位置，把对应行/列也置为 `-inf`。
最终形成的矩阵，既保证了**不偷看未来**，又保证了**不理会 PAD**。
